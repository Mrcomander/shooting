# ストーリー追加の仕様書（視線管理画面）

コードを書かずに、Unityのインスペクターだけで場面・セリフ・分岐を追加するための説明です。

---

## 1. 全体のしくみ

```
場面（GazeScene）
├ 立ち絵：立ち絵Prefab（画像＋当たり判定）
└ 分岐リスト（上から順にチェック）
    └ 分岐
        ├ 条件 … 全部そろったら成立
        └ 結果 … セリフ／ドキドキ／HP／フラグ／次の場面
```

プレイヤーが立ち絵を見る → 条件がそろった分岐が成立する → 結果が実行される → 次の場面へ進む（または同じ場面で見続ける）。これをくり返します。

**ポイント：「分岐1つ ＝ 条件のセット1つ ＋ 結果のセット1つ」。** 条件ごとに別の結果を出したいときは、分岐を分けてください。

---

## 2. ストーリーを追加する手順

1. **立ち絵Prefabを用意する**（`Assets/prehub/Portraits/`）
   - 既存のPrefab（例：`Shiki_Normal`）を選んで Ctrl＋D で複製し、名前を変える。
   - ダブルクリックでPrefabモードを開き、画像を差し替える。
   - Head・Body・Legの当たり判定（四角）を、Rectツール（Tキー）で立ち絵に合わせる。
2. **場面アセットを作る**（`Assets/Scripts/GazeScene/`）
   - Projectウィンドウで右クリック → Create → Game → Gaze Scene。
   - `Portrait Prefab` に、1で用意した立ち絵Prefabを入れる。
3. **分岐を設定する**
   - `Branches` の＋で分岐を追加して、条件と結果を入れる（3〜5章）。
4. **場面をつなぐ**
   - 前の場面の分岐の `Next Scene` に、作った場面をドラッグする。

---

## 3. 分岐のルール

| ルール | 説明 |
|---|---|
| 上から順にチェック | 最初に条件がそろった分岐だけが使われる。**厳しい条件ほど上に置く。** |
| 条件は「全部そろったら」 | 1つの分岐に条件を複数並べると「AかつB」になる。 |
| 「または」は分岐を分ける | 「AまたはB」にしたいときは、分岐を2つ作って同じ `Next Scene` につなぐ。 |
| 1つの場面で1回だけ | 一度成立した分岐は、同じ場面ではもう成立しない。 |
| `Next Scene` が空なら続行 | 結果のあとも同じ場面のまま、残りの分岐をチェックし続ける。 |
| 条件が空の分岐は成立しない | 「それ以外」を作りたいときは、条件に「いつでも」を使う。 |

---

## 4. 条件の一覧

`Conditions` の＋で追加して、`Type` で種類を選びます。種類ごとに使う欄だけ埋めればOKです（欄名にマウスを乗せると説明が出ます）。

| 種類（Type） | 意味 | 使う欄 | 例 |
|---|---|---|---|
| 見ている | 今その部位を見ている | Part | 頭を見たら |
| 見続けた秒数 | その部位を○秒以上見続けている | Part・Seconds | 足を3秒見たら |
| 見た回数 | この場面でその部位を○回以上見た | Part・Count | 頭を3回見たら |
| 見た順番 | 指定の順に見た（間に別の部位を見てもOK） | Order | 足→頭の順に見たら |
| フラグ | 指定のフラグが立っている | Flag Name | `LookedLeg` が立っていたら |
| ドキドキ値 | ドキドキ値が○以上 | Value | 1200以上なら |
| HP | HPが○以上 | Value | 500以上なら |
| いつでも | 必ず成立する | なし | エンド判定の「それ以外」 |

※「見ている」は一瞬通過しただけでも成立します。通りすがりで反応させたくないときは「見続けた秒数」を0.5秒くらいで使ってください。

---

## 5. 結果の一覧

| 欄 | 内容 |
|---|---|
| Lines | セリフのリスト。上から順に一定時間ずつ表示される。<br>・`Speaker`：話す人の名前<br>・`Text`：本文（Enterで改行できる）<br>・`Portrait Prefab`：このセリフで表情を変えたいときだけ立ち絵Prefabを入れる（空なら変わらない）<br>・`Id`：空でOK |
| Love Change | ドキドキ値の増減（＋で増える、−で減る） |
| Hp Change | HPの増減（＋で回復、−でダメージ） |
| Set Flags | 立てるフラグ名（＋で複数可） |
| Next Scene | セリフのあとに進む場面。空なら今の場面のまま |

セリフが流れている間は、当たり判定がOFFになり、見ても反応しません。

---

## 6. よく使うパターン

**部位ごとに別の反応**（同じ場面で何度も反応させる）

| 分岐 | 条件 | 結果 | Next Scene |
|---|---|---|---|
| 頭を見た | 見続けた秒数：Head／1 | セリフ「なに？」 | 空 |
| 足を見た | 見続けた秒数：Leg／2 | ドキドキ＋50、フラグ `LookedLeg` | 空 |

**回数で段階的に反応**（多い回数を上に）

| 分岐 | 条件 | 結果 | Next Scene |
|---|---|---|---|
| 3回目 | 見た回数：Head／3 | セリフ「さっきから何？」 | 次の場面 |
| 2回目 | 見た回数：Head／2 | セリフ「また？」 | 空 |
| 1回目 | 見た回数：Head／1 | セリフ「なに？」 | 空 |

**エンド判定**（判定専用の場面を作り、セリフは空にする）

| 分岐 | 条件 | Next Scene |
|---|---|---|
| グッド | フラグ：A ＋ ドキドキ値：1200 | GoodEnd |
| ノーマル | ドキドキ値：1000 | NormalEnd |
| バッド | いつでも | BadEnd |

---

## 7. 注意すること

- **フラグ名は一字一句同じに。** 大文字・小文字やスペースが違うと別のフラグになります。
- **当たり判定の色。** 調整中は半透明で見えるようにし、本番はColorのA（透明度）を0にする（透明でも反応します）。
- **文字や飾りの画像は Raycast Target をOFFに。** ONのままだと、その下の当たり判定にマウスが届きません。
- **ドキドキ値の初期値**は `GameManager` の `Main Love Meter`（今は1000）。
- **フラグがPlayをまたいで残る場合**は、Edit → Project Settings → Editor → Enter Play Mode Settings の「Reload Domain」をONに。

---

## 8. コードが必要になるとき

次の場合だけ、プログラム担当に相談してください。

- 新しい部位（例：キーホルダー）を増やす → `BodyPart` に追加
- 新しい種類の条件・結果を増やす → `GazeConditon.cs` に追加
- 同じ分岐を何度でも成立させたい（例：足を見るたびに毎回ドキドキ＋10）
- 時間切れでエンドに進めたい
